# Example Projects

Open these `.loid` files in Melon Synth to see how projects are structured.

## demo-melody.loid
A simple ascending/descending melody — great for testing voicebank playback and getting familiar with the piano roll.

## japanese-phrases.loid
Common Japanese syllables arranged as a vocal exercise. Useful for testing MLC lyric conversion with JP CV voicebanks.

---

To open: **File → Open Project** or drag the `.loid` file onto the app window.
